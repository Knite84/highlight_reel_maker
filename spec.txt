Project Specification: Local AI Media Understanding & Highlight Reel Generator

Objective

Design and build a Windows-first, local-only AI application that transforms folders containing photos and videos into a searchable media knowledge base capable of generating high-quality highlight reels.

The emphasis is not on simply creating highlight videos.

The emphasis is on creating a reusable media understanding pipeline whose outputs can later power many workflows such as:

- Vacation highlight reels
- Family videos
- Drone footage
- GoPro footage
- Time lapse summaries
- Home renovation progress videos
- YouTube rough cuts
- Searchable media archives
- Future AI-powered media editing capabilities

The application should be architected as a platform rather than a single-purpose script.

---

Guiding Principles

1. Everything runs locally.

2. User media never leaves the computer.

3. Expensive AI analysis is performed only once.

4. Every subsequent edit should reuse cached knowledge.

5. AI planning should be separated from rendering.

6. Every stage should produce reusable artifacts.

7. The architecture should be modular enough to swap vision models, LLMs, embedding models, or rendering approaches in the future.

---

Pass 2

Scene Detection

Automatically detect scene boundaries.

Use FFmpeg and OpenCV.

The user should never manually define scenes.

Over-segmentation is preferred.

Adjacent segments may later be merged.

---

Pass 3

Representative Frame Selection

Automatically select representative frames from each detected scene.

Store them.

Never regenerate unless source media changes.

Pass 5

Vision Model

Analyze each scene independently.

Do NOT summarize entire videos.

Each detected scene receives:

Objects

Actions

Camera motion

People

Emotion

Importance score

Beginning

Middle

Ending

Example:

0.0-8.2

Camera follows two hikers walking uphill through dense pine forest.

8.2-16.4

Camera slowly pans left revealing mountain stream.

16.4-27.8

Static shot focused on flowing stream and surrounding rocks.

Etc.

---

Pass 6

Embeddings

Create semantic embeddings.

Every scene becomes searchable.

Support queries like:

"waterfalls"

"dogs"

"kids laughing"

"sunset"

"boats"

without relying only on keyword matches.

---

Pass 7

Knowledge Base

Persist everything.

Nothing should require another AI vision pass unless media changes.

Development Philosophy

Favor clean architecture over speed.

Favor reusable pipelines over shortcuts.

Favor structured data over large language summaries.

Every expensive operation should produce artifacts that can be reused forever.

The goal is to build a local AI media understanding platform whose first application is automatic highlight reel generation, but whose architecture is flexible enough to support many future AI-powered media workflows.
